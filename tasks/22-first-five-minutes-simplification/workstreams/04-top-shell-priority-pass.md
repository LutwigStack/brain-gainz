# 04 Top Shell Priority Pass

## Status

`done`

## Goal

Reduce top shell and side navigation pressure during learner mode.

## Scope

- identify which top context cards are necessary for the current step
- keep campaign and current lesson/route context visible
- demote race/person/city/system environment if they do not help the current action
- reduce duplicate navigation labels
- avoid dense control-panel feeling on first screen
- preserve desktop author power outside learner path

## Done When

- Today first viewport feels task-first
- top shell does not compete with the main CTA
- side navigation is understandable without reading subtitles on every item
