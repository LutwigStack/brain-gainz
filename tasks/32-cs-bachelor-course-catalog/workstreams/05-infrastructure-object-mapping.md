# 05 Infrastructure Object Mapping

## Status

`done`

## Goal

Map courses to future city/atlas infrastructure objects.

## Scope

- course hub names;
- infrastructure object names;
- region visual identity;
- rough gameplay role;
- city/atlas mapping.

## Requirements

- Each major course should be eligible as a course hub.
- Infrastructure names should clarify meaning, not obscure it.
- Keep Russian learner-facing names.
- Do not require final art/assets.
- Do not create lower nodes.

## Examples

- `Основы программирования` -> `Мастерская кода`
- `Структуры данных` -> `Архив структур`
- `Алгоритмы` -> `Навигационный центр`
- `Базы данных` -> `Городское хранилище`
- `Операционные системы` -> `Ядро города`
- `Машинное обучение` -> `Обсерватория моделей`

## Done When

- Course hubs can appear in city and skill atlas.
- Object names are consistent enough for UI labels and tooltips.


## Legacy naming

This file uses legacy terms (`atlas`, `city`, `POE`, `Карта задач`, `Атлас знаний`, `город`) that were current before the cosmic direction was confirmed in epic 40. The user-facing language is now `Карта знаний`; see epic 48 (this epic) for the documentation migration. The file is kept for context and is superseded by epics 40 and 47.
