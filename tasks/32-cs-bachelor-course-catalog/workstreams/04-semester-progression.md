# 04 Semester Progression

## Status

`done`

## Goal

Draft a reasonable 8-semester progression for the bachelor catalog.

## Scope

- year/semester hints;
- workload balance;
- foundational order;
- project placement;
- elective/advanced placement.

## Requirements

- Treat semester placement as recommendation, not hard lock.
- Year 1 should build programming, math, tools, and proof readiness.
- Year 2 should build structures, algorithms, systems, databases.
- Year 3 should broaden into OS, networks, theory, ML/data, software engineering.
- Year 4 should emphasize advanced topics, projects, security, capstone.
- Keep projects spread through the program, not only at the end.

## Done When

- Every course has a suggested year/semester window.
- The plan feels like a real 4-year program.
- The plan can drive route presets later.
