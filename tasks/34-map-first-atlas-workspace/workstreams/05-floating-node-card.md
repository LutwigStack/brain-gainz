# 05 Floating Node Card

## Status

`planned`

## Goal

Use a floating node card as the first inspection surface.

## Scope

- hover card;
- keyboard focus card;
- tap/select card;
- primary action;
- status summary;
- positioning/collision handling.

## Requirements

- Card shows title, short description, status, route/mastery, and one action.
- Card does not cover the node in a way that blocks navigation.
- Card is not a full lesson.
- Keyboard focus must show the same information.
- Mobile uses selected-node bottom preview.

## Done When

- User can understand a node without opening the right drawer.
- Normal exploration is tooltip/card driven.
