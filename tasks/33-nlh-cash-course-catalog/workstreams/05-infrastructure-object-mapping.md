# 05 Infrastructure Object Mapping

## Status

`done`

## Goal

Map NLH course regions/courses to future city/atlas infrastructure objects.

## Scope

- infrastructure object names;
- region visual identity;
- course hub names;
- gameplay role;
- city/atlas mapping.

## Requirements

- Object names should clarify the learning role.
- Avoid casino/glamour framing.
- Keep risk/control objects visually serious.
- Do not require final art/assets.
- Do not create lower spots.

## Suggested Objects

- `Банкролл и риск` -> `Казначейство`
- `Preflop` -> `Зал диапазонов`
- `Flop` -> `Арена текстур`
- `Turn` -> `Башня давления`
- `River` -> `Суд последней улицы`
- `3-bet pots` -> `Крепость больших банков`
- `Exploit` -> `Разведывательная сеть`
- `GTO/Solver` -> `Лаборатория равновесия`
- `Database review` -> `Архив раздач`
- `Ментальная игра` -> `Комната контроля`

## Done When

- Course hubs can appear in city and skill atlas.
- Object names are consistent enough for UI labels and tooltips.


## Legacy naming

This file uses legacy terms (`atlas`, `city`, `POE`, `Карта задач`, `Атлас знаний`, `город`) that were current before the cosmic direction was confirmed in epic 40. The user-facing language is now `Карта знаний`; see epic 48 (this epic) for the documentation migration. The file is kept for context and is superseded by epics 40 and 47.
