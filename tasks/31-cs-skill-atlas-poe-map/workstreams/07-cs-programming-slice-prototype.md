# 07 CS Programming Slice Prototype

## Status

`done`

## Goal

Build a dense first prototype slice for `Программирование -> Основы программирования -> Мастерская кода`.

## Scope

- prototype content mapping
- 80-150 nodes
- 5-8 branches
- route path
- weak/contested sample states
- boss/checkpoint sample nodes

## Suggested Branches

- язык и синтаксис;
- переменные и типы;
- управление потоком;
- функции;
- коллекции и данные;
- ошибки и отладка;
- ввод/вывод;
- мини-проекты и проверки.

## Requirements

- The slice must be dense enough to reject the current linear layout.
- Atomic nodes should be real CS concepts, not placeholder "lesson 1/2/3".
- Boss/checkpoint nodes should sit at branch ends or convergence points.
- Route should cross the atlas as an overlay.
- Use Russian learner-facing names.

## Done When

- `Мастерская кода` no longer appears as a single horizontal line.
- Prototype demonstrates the future 1000+ node map direction.
- User can zoom, hover, select, and start/check a node from the map.
