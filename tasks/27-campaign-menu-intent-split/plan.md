# Campaign Menu Intent Split Plan

## Order

1. Define the three user intents and section rules.
2. Build `Продолжить обучение`.
3. Build `Начать готовый курс`.
4. Build `Создать свою кампанию`.
5. Move archive/system content into secondary placement.
6. Tighten mobile layout.
7. Run browser QA.

## Main Risk

Do not make the screen more explanatory. Make the structure itself obvious.

## UX Rule

Each section should answer one intent:

- continue something I already started
- start a ready course
- create my own campaign

Archive, restore, and developer/system tools are support actions, not primary learner choices.

## QA Targets

- no personal campaigns
- one personal campaign
- multiple personal campaigns
- archived campaign
- ready CS course template
- system/developer template
- create custom campaign
- desktop 1280px
- mobile 390px
