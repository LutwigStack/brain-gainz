# 02 Continue Learning Section

## Status

`done`

The UI implementation demonstrates the continue-learning behavior below.

## Goal

Make continuing an existing campaign the clearest path.

## Scope

- section title: `Продолжить обучение`
- show strongest continue CTA for last/open personal campaign
- show compact campaign summary: name, progress, XP, next lesson when available
- provide expandable `Все мои кампании`
- include `Открыть` and secondary archive action per campaign

## Done When

- user can immediately continue the right campaign
- multiple personal campaigns are scannable
- archive action does not compete with continue

## Post-UI Close Check

- Existing personal campaigns prioritize the primary continue path.
- Secondary archive actions remain visually below or weaker than continue/open actions.
