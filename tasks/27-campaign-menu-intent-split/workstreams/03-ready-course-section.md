# 03 Ready Course Section

## Status

`done`

The UI implementation demonstrates the ready-course behavior below.

## Goal

Make developer-provided courses feel like learner-ready courses.

## Scope

- section title: `Начать готовый курс`
- show CS course/template as a learner course card
- primary action: `Создать копию и начать` or shorter equivalent
- secondary action: `Посмотреть`
- remove jargon such as `многоразовый шаблон` from learner-primary copy

## Done When

- learner understands this creates their own copy of a course
- ready courses do not look like system/admin rows

## Post-UI Close Check

- Developer-provided courses are presented as learner-ready courses.
- Learner-primary copy avoids system/admin jargon.
