# 04 Custom Campaign Section

## Status

`done`

The UI implementation demonstrates the custom campaign placement below.

## Goal

Keep custom campaign creation available without making it the default first action.

## Scope

- section title: `Создать свою кампанию`
- compact quick settings: name, optional topic/direction, mode if available
- primary action: `Создать кампанию`
- secondary: `Подробные настройки`
- avoid showing a large empty form above existing/ready campaigns

## Done When

- custom creation is easy to find
- it no longer dominates first viewport for learners who just want to continue/start a course

## Post-UI Close Check

- Custom creation is available after continue and ready-course paths.
- The first viewport is not dominated by a large blank custom campaign form.
