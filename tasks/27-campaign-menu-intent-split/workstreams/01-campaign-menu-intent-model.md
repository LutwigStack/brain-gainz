# 01 Campaign Menu Intent Model

## Status

`done`

Implementation demonstrates the section model and visibility rules below.

## Goal

Define the Campaign Menu information architecture before implementation.

## Scope

- list all campaign types currently shown
- classify them into learner intent sections
- define section order and empty states
- define primary/secondary actions per section
- define what ordinary learners should not see by default

## Done When

- implementation can follow a clear section model
- archive/system/developer visibility rules are explicit

## Post-UI Close Check

- The implemented Campaign Menu has three clear learner intent sections.
- Archive, restore, and system/developer content are secondary to learner actions.
